# Changelog

## 1.1.1 — 2026-11-18

- Keep Find and Replace controls usable in narrow editor panes.
- Update editor chrome and line numbers when switching between light and dark appearances.
- Expose tab selection and close actions as separate accessible controls, and keep the selected tab visible.
- Add Control-Tab and Control-Shift-Tab shortcuts for moving between tabs.
- Isolate build and DMG staging directories and preserve other distribution files during packaging.

The download is a Universal 2 build for macOS 13 or later on Apple Silicon and Intel. It is ad-hoc signed and is not notarised by Apple; macOS may require manual first-launch approval.

## 1.1.0 — 2026-11-17

- Restore open tabs and unsaved text between sessions, with checks before overwriting files changed elsewhere.
- Open files from macOS in the existing QuickPad window.
- Offer QuickPad as the default application for plain text files.
